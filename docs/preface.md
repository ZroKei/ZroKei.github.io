# 前言

这里是 ZroKei 的嵌入式学习笔记，用来存放平时折腾单片机时留下的记录。

## 这里有什么

- **单片机**：STM32 标准库、C51、ESP32
- **实时系统**：FreeRTOS 的任务调度与并发原理
- **竞赛**：蓝桥杯嵌入式组的备考与复盘
- **工具链**：VSCode 下的编译、调试环境搭建

## 怎么读

左侧边栏按主题分组，右上角搜索框支持中文分词全文检索；每篇文章底部都标注了最后更新时间，内容有改动会同步更新。

## 关于更新

笔记是边学边写的，难免有理解不到位的地方。如果发现错误，欢迎点每页右下角的「在GitHub编辑本页」直接提修改，或者到 [GitHub](https://github.com/ZroKei) 开 issue。
